# 탭 3: AI 자소서 작성 (AI Cover Letter)

AI 자소서 작성 탭은 기업별 자소서 문항의 의도를 파악하고, 내 '경험 DB'에 있는 실제 사례를 바탕으로 완성도 높은 자소서 초안을 작성해 주는 맞춤형 에이전트 기능입니다.

## 주요 기능
### 1. SWOT 시맨틱 매칭을 통한 경험 추천
- 단순한 키워드 매칭이 아닌, 기업의 직무기술서(JD)와 자소서 문항이 요구하는 의도를 LLM으로 분석합니다.
- 내 경험 DB 중에서 강점(S)을 부각하거나 약점(W)을 극복할 수 있는 가장 최적화된 경험을 AI가 추천해 줍니다.

### 2. 자동 글자수 맞춤 및 초안 생성
- 선택된 경험을 바탕으로 기업이 제한한 글자 수에 꼭 맞게 분량을 자동 조절하여 자소서 초안을 생성합니다.
- LangGraph를 활용한 멀티 노드 워크플로우(문항 분석 -> 매칭 -> 생성 -> 검토)를 거쳐 고품질의 문장을 제공합니다.

### 3. 사용자 통제형 비파괴 원칙
- AI가 생성한 자소서는 덮어쓰기 없이 '제안'의 형태로만 제공됩니다.
- 사용자는 AI가 제시한 문장을 확인한 후 승인한 내용만 반영할 수 있어, 획일화된 AI 자소서의 한계를 극복하고 본인만의 진정성과 독창성을 지킬 수 있습니다.
